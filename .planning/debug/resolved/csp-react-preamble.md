## Resolution

root_cause: worker/index.js applies the production script-src self policy to Vite development HTML; @vitejs/plugin-react's inline Refresh preamble is blocked, so its injected module guard throws from Icon.tsx.
fix: Omit only Content-Security-Policy in Vite development while preserving all other headers and the exact strict CSP by default/deployment; add regression coverage and document the local-only exception.
